    python的虚拟环境设置

    前言

    由于在实际应用过程中，我们通过python下载的依赖库种类版本较多，容易引起冲突。因而考虑通过设置python的虚拟环境，从而实现每一脚本运行的时候都有自己独立的虚拟环境从而实现稳定运行

    虚拟环境工具——venv

    venv是python3中自带的配置虚拟环境的工具

    创建虚拟环境

    python -m venv 文件名

    在对应的路径下会生成我们自己命名的文件夹，里面是全新python环境

    cd到Script目录下查看发现只有pip一个库

    激活虚拟环境

    在Scripts目录下activate.bat激活虚拟环境

    虚拟环境应用

    在虚拟环境中可以进行pip库的随意安装

    python的多版本管理

    前言

    工具脚本的使用过程中，有些需要py3环境有些需要py2环境，而一般情况下只能存在一个py环境这就需要对py进行多版本的管理配置

    下载安装pyenv

    pyenv是管理python多本版的工具，在使用前需要将系统原来的python环境删除

    将下载的pyenv放在英文路径下并重命名为pyenv

    找到bin目录并配置该目录下的环境变量

    再在path中加入

    %PYENV%\bin
    %PYENV%\shims

    验证是否安装成功

    cmd中输入pyenv

    pyenv基本命令

    commands ————-列出所有可用的pyenv命令
    duplicate ————-创建一个重复的python环境
    local ————–设置或显示特定于本地应用程序的Python版本
    global ————–设置或显示全局Python版本
    shell ————–设置或显示特定于shell的Python版本
    install ————–Python构建安装Python版本
    uninstall ————-卸载特定的Python版本
    update ————-更新缓存的版本数据库
    rehash ————-重新安装pyenv垫片（安装可执行文件后运行此操作）
    vname ————-显示当前的Python版本
    version ————-显示当前Python版本及其来源
    version-name —————-显示当前的Python版本
    versions —————–列出pyenv可用的所有Python版本
    exec —————–通过首先准备路径来运行可执行文件，以便选定的Python
    which ————– 显示可执行文件的完整路径
    whence ———————列出包含给定可执行文件的所有Python版本
