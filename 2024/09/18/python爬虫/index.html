python中的类

什么是类

在Python中，类是一个用于创建对象的“蓝图”或模板。每个基于类的实例被称为对象。你可以将类比作汽车的设计图，而对象则是根据这个设计图制造的具体汽车。

类的基本用法

在类当中参数被叫做属性 函数被叫做方法

类的基本特性

继承

也就是继承之前类的属性方法

在新的类中以一个括号的形式继承前面的类

如果上一个类中有不想被继承的属性方法 在前面加两个下划线_ _ 表示私有

多态

多态是指不同的对象可以通过同一个接口，以不同的方式执行同一个方法。这意味着不同的类的对象可以调用同一个方法名，但各自有不同的行为，对于继承的方法我们再进行多态则会直接重写被继承的方法

python多线程

什么是多线程

多线程就是一次性可以同时处理多个任务，在python中由于有一个全局解释器锁 所以导致一次就只能执行一个任务 所以在执行的时候python先在一段时间执行一个任务 执行完了交换另外的任务 执行不完就保留当前状态 交给其他任务实现伪并发 所以python的多线程事伪多线程

进程池

进程池是一个固定的进程集合，由 multiprocessing.Pool 类实现。它的核心思想是：

  • 预先创建若干个进程（数量通常由用户指定，或默认使用 CPU 核心数）。
  • 将任务分发给池中的进程执行。
  • 当任务完成后，进程不会销毁，而是等待新的任务，从而减少进程创建和销毁的开销。

相比手动创建和管理多个 Process 对象（例如之前的 processes = [] 示例），进程池更简洁、高效。

协程

协程是实现异步编程的一种方式

子程序，或者称为函数，在所有语言中都是层级调用，比如A调用B，B在执行过程中又调用了C，C执行完毕返回，B执行完毕返回，最后是A执行完毕。

所以子程序调用是通过栈实现的，一个线程就是执行一个子程序。

子程序调用总是一个入口，一次返回，调用顺序是明确的。而协程的调用和子程序不同。

协程看上去也是子程序，但执行过程中，在子程序内部可中断，然后转而执行别的子程序，在适当的时候再返回来接着执行。

注意，在一个子程序中中断，去执行其他子程序，不是函数调用，有点类似CPU的中断。比如子程序A、B：

  • 协程（Coroutine）：

什么是Ajax
Ajax（Asynchronous Javascript And XML），即是异步的JavaScript和XML，Ajax其实就是浏览器与服务器之间的一种异步通信方式

异步的JavaScript

它可以异步地向服务器发送请求，在等待响应的过程中，不会阻塞当前页面，在这种情况下，浏览器可以做自己的事情。直到成功获取响应后，浏览器才开始处理响应数据。

XML

是前后端数据通信时传输数据的一种格式，现在已经不怎么用了，现在比较常用的是 JSON

所以归纳上述的概念，Ajax就是在浏览器不重新加载网页的情况下，对页面的某部分进行更新。

beautifulsuop4库

BeautifulSoup 是一个用于解析 HTML 和 XML 文档的 Python 库。它能够从网页中提取数据，并以一种易于操作的方式呈现这些数据。BeautifulSoup 通常与网络请求库（如 requests）结合使用，用于网页抓取（Web Scraping）和数据提取。

BeautifulSoup 的主要作用

  1. 解析 HTML/XML 文档：
    • 将复杂的 HTML 或 XML 文档转换为树形结构（解析树），方便遍历和搜索。
  2. 提取数据：
    • 从网页中提取特定的内容，如文本、链接、图片、表格等。
  3. 处理不规范的 HTML：
    • 即使 HTML 文档格式不规范（例如缺少闭合标签），BeautifulSoup 也能很好地处理。
  4. 支持多种解析器：
    • 默认使用 Python 内置的 html.parser，也支持其他解析器，如 lxml 和 html5lib。
