sql 注入审计

正则搜索

我们通过正则匹配 sql 注入的关键词锁定一些敏感函数等

然后根据所在目录 是否存在过滤 是否包含可以利用的变量等选出最可疑的部分

当出现自定义函数时可以追踪函数 找到在什么地方定义的函数

随后进行本地测试 可以通过在原有代码的基础上修改让测试结果明显 或者用动态调试

然后判断有无回显 即判断 sql 注入类型 回显考虑回显类型的 无回显考虑盲注

最后根据数据库拼接 sql 语句即可

mysql 语句监控

当我们想要审计发现 mysql 查询语句的时候 由于代码里面的数据量很大 我们无法一个变量一个变量的追踪 可以借助 mysql 语句监控脚本
